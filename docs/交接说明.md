## 核心原理（一句话）

只把 `game\csgo_lv\pak01_dir.vpk` 改名成 `pak01_dir.vpk.bak`。
这个文件是国服专用的「低暴力素材包」，移开后游戏找不到它，就会回落到默认的红色血液素材。
恢复就是把名字改回去。

**不注入、不改文件内容、不读写游戏内存、不联网。** 这是它不会被杀软误报、也不会被判成作弊的根本原因。

## 怎么编译（**重点，有坑**）

**不要在 Desktop 路径下直接 build。** MSBuild 在 Desktop 环境下会枚举不到源文件，报 CS5001 / CS1555（编译器说看不到 Program.cs），同样文件换个目录就一次通过。

必须走临时目录：

```cmd
mkdir %TEMP%\cs2stage
copy src\Program.cs src\CSBloodToggle.csproj src\app.ico %TEMP%\cs2stage\
cd %TEMP%\cs2stage
%LOCALAPPDATA%\Microsoft\dotnet\dotnet.exe build -c Release -v q
copy bin\Release\net48\CS国服去和谐程序.exe  ← 拷回工作区
```

需要 .NET SDK（不是运行时）。当初用 `dotnet-install.ps1` 装在用户级：
`%LOCALAPPDATA%\Microsoft\dotnet`，版本 8.0.426，不碰系统目录。

首次编译若报 NU1100（NuGet 恢复失败）：
`dotnet nuget add source https://api.nuget.org/v3/index.json`

### 状态机（四态，别简化）

| 状态 | 含义 | 处理 |
|---|---|---|
| `harmonized` | 只有原名 | 正常 |
| `deharmonized` | 只有 .bak | 正常，游戏内红血 |
| `stale` | 两者都在 | Steam 更新把文件重下了，留下孤儿备份。去和谐时删孤儿再移；恢复时保留 Steam 重下的、删孤儿 |
| `unknown` | 都没有 | 提示去 Steam 验证完整性 |

### 两个容易踩的行为约束

1. **`Program.Main` 里只有 `find/state/deharm/restore` 四个词走命令行调试模式**，其他任何参数都必须正常启动 GUI。否则用户把文件拖到 exe 图标上会静默退出，看起来像程序坏了。
2. **单实例锁**用 `Mutex("Local\\CSBloodToggle_SingleInstance_9F2A7C")`。第二次启动不是静默退出，要激活已有窗口（按 exe 自身文件名匹配进程，不依赖窗口标题）。

## 不要擅自改动的东西（用户已验收）

**视觉语言：CLEAN WHITE 液态玻璃。**

- **零反光、零描边、零阴影**——这是用户反复强调过的，任何高光、镜面、白边、投影都会被要求删掉
- 玻璃卡片 `alpha 98`，按钮 `158`（磨砂款 `120`）
- 按钮是**窄条居中**：`x=74, w=260`，不占满宽
- 光斑动画：有焦点 120ms / 失焦 480ms，相位增量用 `PhasePerMs` 常量与帧间隔解耦（改帧率不改变视觉速度）
- 标题必须带 `· made by xixi❤️`
- 路径行「（点此重新查找）」那一段是**单独一个加粗 Label**，不是整行加粗

## 历史踩坑（照着做能省几小时）

1. **WinForms z 序反直觉**：后 `Controls.Add` 的控件在**底层**。任何与已有 Label 位置重叠的自绘控件，Add 之后必须 `BringToFront()`。这个坑踩了两次。
2. Panel 设 `BackColor = Transparent` 前必须 `SetStyle(ControlStyles.SupportsTransparentBackColor, true)`，否则启动即崩。
3. 截图脚本：必须 `SetWindowPos(HWND_TOPMOST)`，否则截到被遮挡的其他窗口；加了单实例锁后**先 taskkill 再等 2 秒**，否则新实例被锁拦住、拍到的是正在退出的旧窗口。
4. 测 CPU 占用必须先预热 6 秒再连测多次。启动阶段 JIT 会让数值虚高 5~10 倍（曾据此误判「待机 16% CPU」，实际只有 1.5%）。
5. 读回自己写的 CRLF 文本文件要用**二进制模式**，Python 文本模式会把 CRLF 规范化成 LF，导致行数统计错误。
6. **改文案别用 `...`**。那是 Windows「点击会弹窗」的老惯例，用户看不懂，以为文字被截断，被明确要求去掉。
7. 说明文档里的文件大小别写死字节数，写「约 XX KB」，否则每次改版都要同步。

## 验证情况

**已通过真机验证，用户确认可用（2026-10-22）。**

完整链路跑通：点「去和谐」→ 状态变「已去和谐（红血）」→ 进游戏确认是红血 → 玩完点「恢复」→ 回到官方原状。

这意味着 `game\csgo_lv\pak01_dir.vpk` 这个路径假设是**成立的**，没有被完美世界改动过。

### 但有个环境限制要知道

开发机上 `D:\Program Files (x86)\Steam\steamapps\common\Counter-Strike Global Offensive` 是个 **0 字节的空壳目录**（`steamapps` 下没有 `appmanifest_730.acf`，属卸载残留）。

所以本机**只能跑自动化回归测试**——用临时搭的假 CS2 目录结构模拟各种状态。真实游戏效果没法在本机验证。

如果以后改了核心逻辑（比如改了操作的文件名、改了状态机），改完仍然需要找一台装了**国服** CS2 的机器实测一遍。

## 已知局限（用户明确说不做，别自作主张加）

- **无 DPI 感知声明**：125% / 150% 缩放的高分屏上会被 Windows 位图拉伸而模糊。修起来要连带改所有硬编码坐标，改动面大，用户决定不做。
- **无「忘记恢复」提醒**：去和谐后直接关程序、接着开游戏，可能撞上 Steam 自动修复。
- **无数字签名**：首次运行可能被 SmartScreen 拦一次，点「更多信息 → 仍要运行」即可。
- **只适用 Steam 国服 CS2**：国际服本来就没有 `csgo_lv`，用不上；完美对战平台（PAC）有独立的文件校验层，未做验证，可能触发强制修复。
