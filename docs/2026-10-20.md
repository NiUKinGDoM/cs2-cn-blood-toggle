- 十三轮（代码复审）：爹要求「再看看有啥问题没」，逐行复查后又修了 4 个问题。
  - **真 bug①：`OnBrowse` 手动选目录不取消自动检测**。启动后 1.5s 内手选目录时，`detecting` 仍为 true → `RefreshState()` 直接 return（界面卡在"正在检测"）；更糟的是后台线程回来 `lvDir = r.LvDir`（可能 null）会**覆盖用户手动选的目录**。修法：新增 `CancelDetect()`，选目录成功后先作废检测。
  - **真 bug②：`DetectAsync` 可重入**。点路径行重复触发会起多个后台线程。修法：改成 token 机制——`detectToken`(0=无检测在跑) + `detectTokenSeq` 发生器，回调里 `if (detectToken != token) return;` 直接丢弃过期结果且**不触碰任何状态**。踩坑记录：第一版写成 `if (detecting) return;` 会因为字段初值 `detecting=true` 导致首次检测根本不启动；也不能用「序号比较后清 busy 标志」的写法，否则 CancelDetect 后旧线程回来会误清新检测的锁。
  - **真 bug③：空壳 CS2 目录诊断误报**。本机 `Counter-Strike Global Offensive` 是 0 字节空壳，但程序报"可能是国际服版本"——误导。修法：`FindLvDirEx` 改为返回 `DetectResult{LvDir, Cs2Root, Cs2RootEmpty}` 结构，用 `Directory.GetFileSystemEntries(root).Length == 0` 判空壳，并优先保留"有内容"的那个 CS2 目录；UI 分三档文案（空壳残留 / 国际服 / 完全没装）。
  - **真 bug④：文件被占用时弹英文异常**。新增 `FriendlyIoError(ex)`：UnauthorizedAccessException → 提示管理员运行；IOException → 提示 Steam 正在更新/校验、先退出 Steam。`File.Move` / `File.Delete` 失败都走它。
  - 复审结论：`ValidateLvDir` 在去和谐状态（只有 .bak）下仍正常（它查的是 csgo_lv **目录**，改名不影响）✅；`.bak` 不会被 Steam 校验视为异常文件 ✅；同目录 `File.Move` 是原子改名，无中间态风险 ✅。
  - 未修但已知：① 无 DPI 感知声明（本机 96DPI/100%，1920×1080，所以现在不糊；拷到 125%/150% 高分屏会位图拉伸变糊，且布局是硬编码像素，直接开 DPI 感知会变小，需配套缩放改造）；② 无「忘恢复」提醒（去和谐后直接关程序，开游戏仍可能撞 Steam 修复）；③ 无数字签名，首次运行可能被 SmartScreen 拦一次。

  - 修 1：**目录失效提示误导**。选了目录后卸载/移动游戏，旧逻辑报"目录里没有 pak01_dir.vpk，可能游戏文件不完整"（错的）。现在 `RefreshState` 先判 `Directory.Exists(lvDir)`，失效则明确说"之前选的目录已经不存在了（游戏可能被卸载或移动）"。
