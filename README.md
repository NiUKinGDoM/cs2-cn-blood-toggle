# CS 国服去和谐（已失效存档）

> ## ⚠️ 本项目已失效，不要再用
>
> **失效时间：2026-10-24**
>
> CS2 更新后，本工具的操作会让游戏**直接崩溃无法启动**。
> 已经用了的请立刻恢复文件（方法见下），或走 Steam「验证游戏完整性」。

一个 CS2 国服血液效果切换工具。曾经可以通过重命名游戏资源包，让国服显示红色血液，玩完再恢复原样。

现在这条路被游戏更新堵死了。这个仓库留着，作为「旧方案为什么不行」的记录，也方便后续有人找到新解法时继续维护。

---

## 立刻恢复游戏

如果你已经用本工具点了「去和谐」，然后游戏报错进不去，按顺序试：

1. **打开本工具，点「恢复和谐」**
2. **手动改名**：进
   `...\Counter-Strike Global Offensive\game\csgo_lv\`
   把 `pak01_dir.vpk.bak` 改回 `pak01_dir.vpk`
3. **Steam 验证完整性**（最保险）：
   库里右键 CS2 → 属性 → 已安装文件 → 验证游戏文件的完整性

## 为什么失效

2026-10-24 前后的一次 CS2 更新改了资源加载逻辑。

### 旧行为（本工具依赖的前提）

`game\csgo_lv\pak01_dir.vpk` 是国服专属的**低暴力素材包**（`csgo_lv` = low violence）。
把它改名移开之后，引擎找不到它，就会回落到内置的默认红血素材。

这个说法在多个社区教程里长期存在，在旧版本上确实成立。

### 新行为

同一个文件，现在被列进了**必需资源**列表。

移开后再启动游戏，直接弹框退出：

```
FATAL ERROR: E:\Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo_lv\pak01_dir.vpk
Failed to load file (missing)!
```

游戏不再「回落」，而是拒绝启动。**只要这个文件不在，游戏就进不去。**

---

## 现在能怎么办

### 方案 A：改启动参数（推荐先试这个）

Steam 库 → 右键 CS2 → 属性 → 通用 → 启动选项，填：

```
-worldwide
```

如果原来有 `-perfectworld`，先删掉。

**原理**：让游戏以国际服模式运行，不加载 `csgo_lv` 这个国服和谐包，血液自然是红色。
**完全不动游戏文件**，所以不会被 Steam 校验覆盖、也不会因为版本更新而失效。

**代价**（必须清楚）：

| 项目 | 影响 |
|---|---|
| 服务器 | 匹配到国际服节点（中国香港、新加坡、日本、韩国等） |
| 延迟 | 比国服高 |
| 账号数据 | 国服/国际服的数据、段位不互通 |
| 完美平台 | 从 Steam 直接启动才生效；平台启动可能被覆盖 |

**结论：想要红血，基本等于放弃国服。**

### 方案 B：接受国服的和谐效果

什么都不动，接受石油色血液。这是唯一能保住「国服 + 低延迟」的选择。

### 方案 C：改 vpk 内容（不推荐）

理论上可以保留文件、只替换内容。但：

- 需要国际服同名的 vpk 文件
- 会被 Steam 完整性校验覆盖掉
- 完美平台（PAC）有独立的文件校验，可能判定为篡改

没验证过，风险高于收益，不建议尝试。

---

## 一句话实话

**「国服 + 红血」这个组合，在当前游戏版本下大概率已经做不到了。**

不是技术不够，是游戏本身把口子封了。要么红血但去国际服，要么留国服但接受和谐。

### 构建

**不要在 Desktop 路径下直接 build**，MSBuild 会枚举不到源文件，报 CS5001 / CS1555。必须复制到临时目录：

```cmd
mkdir %TEMP%\cs2stage
copy src\Program.cs src\CSBloodToggle.csproj src\app.ico %TEMP%\cs2stage\
cd %TEMP%\cs2stage
dotnet build -c Release -v q
copy bin\Release\net48\CS国服去和谐.exe  ← 拷回
```

需要 .NET SDK（不是只有运行时）。

### 代码结构

| 类 | 职责 |
|---|---|
| `GameToggle` | 业务逻辑：找游戏目录、校验、四态状态机、去和谐 / 恢复 |
| `Disclaimer` | 免责声明文案 |
| `InfoDot` | 标题后的小圆圈 i，自绘 |
| `MainForm` | 窗口、液态玻璃背景、自动检测流程、事件 |
| `Program.Main` | 单实例锁 + 参数白名单 + 全局异常兜底 |

### 当时实现过的功能

- 自动检测 Steam 库里的 CS2 安装目录（注册表 + `libraryfolders.vdf`）
- 四态状态机：`harmonized` / `deharmonized` / `stale`（Steam 重下产生孤儿备份）/ `unknown`
- 单实例锁，第二次启动会把已有窗口拉到前台
- 只读属性自动处理、文件被占用时的人话提示
- 纯自绘的液态玻璃界面（零反光零描边零阴影）

### 已知的坑

1. **WinForms z 序反直觉**：后 `Controls.Add` 的控件在**底层**，重叠的自绘控件必须 `BringToFront()`
2. Panel 设 `BackColor = Transparent` 前必须 `SetStyle(SupportsTransparentBackColor, true)`
3. 测 CPU 要先预热 6 秒（JIT 会让数值虚高 5~10 倍）
4. 读自己写的 CRLF 文件要用二进制模式，否则会被规范化成 LF
5. 按钮文案别用 `...`（Windows「会弹窗」惯例，用户看不懂，以为是截断）
